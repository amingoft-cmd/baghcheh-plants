# باغچه — وب‌سایت عمومی ۱۸ گلدان

نسخه آماده انتشار رایگان روی GitHub Pages، راست‌به‌چپ و مناسب موبایل.

- `index.html`: صفحه اصلی با فهرست ۱۸ گلدان، جستجو و دسته‌بندی
- `P-01/index.html` تا `P-18/index.html`: صفحه مستقل هر گلدان
- `assets/style.css`: طراحی یکپارچه
- `data/plants.json`: فهرست اولیه؛ بدون داده خصوصی یا کلید API

## انتشار

1. در حساب GitHub یک مخزن **Public** جدید با نام `baghcheh-plants` بسازید؛ گزینه افزودن README را فعال نکنید (یا اگر فعال کردید مشکلی ندارد).
2. پوشه‌های سایت و فایل‌های آن را در ریشه مخزن قرار دهید (ZIP را همان‌طور فشرده بارگذاری نکنید).
3. Settings > Pages > Build and deployment > Source: `Deploy from a branch`، Branch: `main` و پوشه `/(root)`، سپس Save.
4. پس از انتشار، آدرس پیشنهادی `https://USERNAME.github.io/baghcheh-plants/` است؛ آدرس واقعی را در بخش Pages تأیید کنید.

## لینک QR

پس از بررسی آدرس عمومی، QRها را برای مسیرهای `/P-01/` تا `/P-18/` تولید کنید. از ساخت QR قبل از انتشار واقعی پرهیز کنید.

## امنیت

Google Sheets اصلی خصوصی باقی می‌ماند. این سایت هیچ توکن یا گذرواژه‌ای ندارد. تصاویر داخلی دفتر عمداً در نسخه عمومی قرار نگرفته‌اند تا قبل از تأیید منتشر نشوند.

## امکانات متصل‌نشده

ثبت آبیاری، نمایش وضعیت زنده و اعلان تلگرام **فعلاً پیاده‌سازی نشده‌اند**. برای آن‌ها یک سرور/Apps Script با کنترل دسترسی لازم است. این صفحات فعلاً فقط خواندنی هستند.
