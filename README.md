# باغچه 🌿

وب‌سایت نمایشی فارسی باغچه برای ۱۸ گلدون با QR-ready profile URLs.

- صفحه اصلی `index.html`
- صفحه اختصاصی هر گلدون `P-01/index.html` تا `P-18/index.html`
- استایل `assets/style.css`
- داده اولیه عمومی `data/plants.json`

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save.

آدرس سایت پس از فعال شدن: https://amingoft-cmd.github.io/baghcheh-plants/

## حریم خصوصی
هیچ توکن، گذرواژه، لینک خصوصی عکس یا دیتابیس مدیریتی در این مخزن وجود ندارد. قابلیت ثبت آبیاری و یادآوری تلگرام هنوز متصل نشده‌اند؛ این نسخه صرفاً یک کاتالوگ عمومی خواندنی است.
